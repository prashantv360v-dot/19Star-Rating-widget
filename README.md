# ⭐ Star Rating Widget

## 📌 About the Project

The **Star Rating Widget** is a simple web application that allows users to rate items using stars. Users can select a rating from 1 to 5 stars, with interactive visual feedback.

## ✨ Features

- ⭐ Interactive 5-star rating system
- 🖱️ Click to select a rating
- 🎨 Hover effects on stars
- 🔄 Instant visual feedback

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
19star-rating-widget/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Click the stars to select your rating.

## 🎯 Project Purpose

This project helps beginners learn DOM manipulation, event handling, CSS hover effects, and interactive UI development using JavaScript.
